# FLEXI BAG INVENTORY

플렉시백(액체 화물용 컨테이너 라이너)을 **시리얼 단위로 관리**하는 AI 재고관리 솔루션입니다.
작업 오더 **메일 수신 → 자동 파싱 → 예상 재고 반영**, 현장 **라벨 사진 OCR → 시리얼 대조 → USED 차감**까지를 하나의 워크플로우로 묶었습니다.

---

## 1. 빠른 시작 (심사·데모용)

1. 이 폴더(`FLEXIBAG_DEMO`)를 통째로 PC에 복사합니다.
2. **`START_DEMO.bat`** 파일을 더블클릭합니다.
3. 잠시 후 실시간 메일 수신 서버가 켜지고, 데모 화면(`flexibag-inventory-ai-ocr.html`)이 자동으로 열립니다.

> ⚠️ 검은색 **"FLEXIBAG Live Mail Server"** 창은 데모가 끝날 때까지 닫지 마세요. (닫으면 실시간 수신이 멈춥니다.)

### Python 설치 여부에 따라
- **Python이 없어도 됩니다.** `FlexibagMailServer.exe`(단일 실행 파일)가 포함되어 있어, `START_DEMO.bat`이 자동으로 이 exe를 사용합니다.
- Python이 설치되어 있으면 exe 대신 `python scripts/live_email_dashboard.py`로 실행할 수도 있습니다.

---

## 2. 주요 기능

| 화면 | 설명 |
|------|------|
| **대시보드** | 거점별 실제 재고·예상 재고, 재주문 경보, 기준일(오늘 자동 적용) |
| **실시간 메일 수신** | 전용 메일함을 IMAP으로 폴링해 작업 오더 메일을 자동 수신·파싱 |
| **이메일 파싱** | 정규식 1차 + LLM 폴백으로 BKG·작업일·POL/POD·수량·거점 추출 |
| **30/60/90일 예상 재고** | 확정 일정 + 과거 USED 시계열(가중 이동평균)로 예상 필요 수량·예측 재고 산출 |
| **사진 OCR 확인** | 라벨 사진 → 시리얼 자동 판독 → 재고 원장 대조 → 사람 확인 후 USED 차감 |
| **경보 및 처리 이력** | 중복 USED·거점 불일치·미등록 시리얼 차단 내역과 감사 로그 |

---

## 3. 동작 원칙

- **메일 수신만으로는 재고를 차감하지 않습니다.** 확정 일정은 *예상 재고*에만 반영됩니다.
- **실제 재고 차감은 현장 사진 OCR을 사람이 확인한 뒤에만** 일어납니다 (human-in-the-loop).
- OCR이 읽은 값은 *후보*이며, 운영자가 최종 확인한 시리얼만 USED 처리됩니다.

## 4. 폴더 구성

```
FLEXIBAG_DEMO/
├─ START_DEMO.bat                  ← 더블클릭으로 데모 시작
├─ FlexibagMailServer.exe          ← 실시간 메일 수신 서버 (Python 불필요)
├─ flexibag-inventory-ai-ocr.html  ← 데모 화면 (단일 HTML 앱)
├─ flexibag.db                     ← 재고/일정/이력 데이터베이스(SQLite)
├─ .env.mail                       ← 메일 수신 계정 설정 (IMAP)
├─ scripts/                        ← 메일 수신·파싱 서버 코드
├─ src/                            ← 파서·재고·OCR·DB 모듈
├─ data/                           ← 시드 데이터 및 수신 결과
└─ uploads/                        ← 업로드된 사진 보관
```

---

## 5. 실시간 메일 수신 설정 (`.env.mail`)

전용 Gmail 계정으로 작업 오더 메일을 받아 파싱합니다. 수신 주기 등은 `.env.mail`에서 조정합니다.

```
IMAP_HOST=imap.gmail.com
IMAP_PORT=993
IMAP_USER=<수신 전용 메일 주소>
IMAP_PASS=<앱 비밀번호>
POLL_SECONDS=180          # 메일 확인 주기(초)
ALLOWED_SENDERS=          # 비우면 모든 발신자 허용
```

> 운영 환경에서는 이 계정의 앱 비밀번호를 별도 관리하고, 데모가 끝나면 재발급하는 것을 권장합니다.

## 6. 문제 해결

| 증상 | 원인 / 해결 |
|------|------|
| 화면에 "실시간 수신 서버 연결 대기 중 · Failed to fetch" | 메일 수신 서버가 꺼져 있음 → `START_DEMO.bat` 다시 실행 (서버 창이 떠 있는지 확인) |
| OCR이 시리얼을 못 읽음 | 사진을 더 가까이·정면으로 촬영, 또는 confirmed_serial을 직접 입력 |
| 브라우저 OCR이 안 됨 | Tesseract.js를 인터넷(CDN)에서 불러오므로 **인터넷 연결**이 필요합니다 |
| 기준일이 과거로 보임 | 화면을 새로고침하면 오늘 날짜가 자동 적용됩니다 |
